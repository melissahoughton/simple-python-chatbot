# Simple Python Chatbot

This project is a simple chatbot application built using Python. It serves as an introductory exercise for high school students to learn about programming concepts such as conditionals, functions, and user interaction.

## Development with GitHub Codespaces

You can develop and run this chatbot directly in your browser without installing anything!

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://github.com/codespaces/new?hide_repo_select=true&ref=main&repo=melissahoughton/simple-python-chatbot)

Simply click the button above to create a new Codespace. Once it's ready, you can run the chatbot by typing `python app.py` in the terminal.

## Project Structure

- `app.py`: The main entry point of the chatbot application. This file contains everything needed for the chatbot, including the responses dictionary and the main interaction loop. The single-file design makes it easy for students to understand and modify.

## Local Development

If you prefer to run the chatbot locally:

1. Ensure you have Python installed on your machine.
2. Clone the repository or download the project files.
3. Navigate to the project directory in your terminal.
4. Run the chatbot using the command:
   ```
   python app.py
   ```

## Modifying the Chatbot

Students are encouraged to modify the responses dictionary in `app.py` to add new responses or change existing ones. They can also enhance the logic to make the chatbot more interactive.

### Suggested Exercises:
1. Add more response patterns to the responses dictionary
2. Create a more advanced greeting that asks for the user's name
3. Add simple math functionality (e.g., "calculate 2+2")
4. Implement a help command that explains how to use the chatbot

Happy coding!
